I initially tried to develop the script by using lumped ports centered on the via i.e. z-directed lumped port as a box of half-width `r` in x and y, centered on the via. But this failed. When I checked the logs, it was evident that at 0.25GHz, every one of the 16 ports reflected  into itself. The port box was centred on the via and fully contained the PEC via cylinder.
![[Pasted image 20260711035812.png]]

I later tried to troubleshoot this issue with different versions - trying out to fill the gap with a z-directed port and then radial ports across the antipad but they remained unstable with no major improvement to the simulation.

When I explored the documentation and other openEMS community channels (reddit), I got an idea of using CoaxialPort. the native Coaxial port was not available in the openEMS build version I was using so had to update it with the latest build and after trying out different variations in this - lossy coaxial stub fix, fixing the dielectric loss (KAPPA_ANCHOR_HZ = 28 GHz), by anchoring it to the Nyquist frequency by following the convention in the MSL tutorial, and replacing the PML_8 with MUR boundaries, the final version was fixed and was ready for validation.

Latent Space TTO & Curricullum TTO combined (Final version for the Inverse model)

Inspired from Pascal Notin, José Miguel Hernández-Lobato, Yarin Gal, "Improving black-box optimization in VAE latent space using decoder uncertainty", https://doi.org/10.48550/arXiv.2107.00096) for Latent Space TTO and (Liu, Z.; Shan, G.; Chen, Z.; Yang, Y. Physics-Guided Neural Surrogate Model with Particle Swarm-Based Multi-Objective Optimization for Quasi-Coaxial TSV Interconnect Design. _Micromachines_ **2025**, _16_, 1134. https://doi.org/10.3390/mi16101134) with passivity for Curriculum TTO.

in the baseline script the TTO descended directly on the geometry vector **x** and it drove `tan δ` to 0.10, 0.33, 0.63 on samples 0/100/250, against a physical range of ~0.01–0.03 by cheating the loss function to fit the curve. So I tried to optimize the latent space **z** instead of the geometry vector **x**. Now the Adam holds the latent space z (16-dimensions) adn the loss function now focus on the z score with no distortion and gradient exploitation. 

When ran with the Latent TTO there was a dramatic improvement in the results and the geometry generated by the inverse model followed physical constraints and also generated manufacturable design metrics.
